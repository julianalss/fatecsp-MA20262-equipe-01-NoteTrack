# NoteTrack — Painel de Performance de Notebooks no Mercado Livre



**Tema:** Varejo e E-commerce: Análise de Notebooks Lançados em 2025.
**Instituição:** FATEC São Paulo — Curso de Tecnologia em Análise e Desenvolvimento de Sistemas.
**Disciplina:** Microinformática Aplicada (ILP590) — Prof. Veríssimo (Semestre: 2º/2026).

## 📌 Sobre o Projeto

O **NoteTrack** é uma plataforma de inteligência e análise de dados desenvolvida para o mercado de e-commerce de notebooks lançados em 2025. O projeto conecta dados coletados via API pública do Mercado Livre, centralizados e tratados em planilhas estruturadas e banco de dados relacional, culminando em um dashboard interativo de apoio à decisão no Power BI.

### 🎯 Problema e Pergunta Central

Os dados de anúncios, preços e configurações técnicas estão atualmente dispersos e sem padronização no marketplace. Este projeto visa responder à seguinte pergunta central:

> *"Como o preço médio dos notebooks lançados em 2025 no Mercado Livre varia de acordo com o modelo, o tipo de processador, a quantidade de memória RAM e a GPU utilizada?"*
> 

## ⚙️ Arquitetura e Pipeline de Dados

A solução segue rigorosamente o pipeline evolutivo estabelecido na disciplina:

`Dado Bruto (API Mercado Livre) → Excel Avançado → Power Query → Power Pivot/DAX → VBA → SQL → API/Web → Power BI`
